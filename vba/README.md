# VBA 소스 (참고용)

`KESCO_검사ERP_2026.xlsm` 안에 들어 있는 VBA 프로젝트의 소스 사본입니다 (UTF-8).
파일을 직접 가져오려면 VBE(Alt+F11) > 파일 > 가져오기를 쓰되, 한글 깨짐을 피하려면 메모장에서 "ANSI(CP949)"로 다시 저장한 뒤 가져오세요.
`frmCalendar.frm` 은 디자이너 데이터(.frx)가 필요해 xlsm 안에 이미 들어 있는 폼을 그대로 쓰는 것이 안전합니다.

| 파일 | 역할 |
|---|---|
| Module1_공통함수 | 시트/컬럼 상수, 원데이터 읽기, 검사자 별칭 정규화, 근무자(휴가 제외) 계산, 설정 읽기, 로그 |
| Module2_자동배분 | 원데이터에서 선택일 업무를 읽어 5단계 자동배분 → 09_배분결과 저장 |
| Module4_현황판 | 11_일일대장 오른쪽(N열~) 배분현황판 격자·블록·드래그 이동 |
| Module5_ERP | 일일대장(+현황판) / 월대장 렌더링, 인쇄·PDF, 결과 반영, 원데이터 입력 자동 정리 |
| frmCalendar | 달력 날짜 선택 팝업 |
| Sheet11 / Sheet12 / Sheet13 / 현재_통합_문서 | 10_원데이터 / 11_일일대장 / 12_월대장 / 통합 문서 이벤트 |
