# VBA 소스 (참고용)

`KESCO_검사ERP_2026.xlsm` 안에 들어 있는 VBA 프로젝트의 소스 사본입니다 (UTF-8).
직접 가져오려면 VBE(Alt+F11) > 파일 > 가져오기를 쓰되, 한글 깨짐을 피하려면 메모장에서 "ANSI(CP949)"로 다시 저장한 뒤 가져오세요.
`frmCalendar.frm` 은 디자이너 데이터(.frx)가 필요해 xlsm 안에 이미 들어 있는 폼을 그대로 쓰는 것이 안전합니다.

| 파일 | 역할 |
|---|---|
| Module1_공통 | 시트/컬럼 상수, 원데이터 읽기(캐시), 설정·명단·지역표 읽기, 로그, 속도용 FastBegin/FastEnd |
| Module2_자동배분 | 화면 입력 기준 5단계 자동배분 (04_지역표 클러스터 기반 근접도), 결과 일괄 저장 |
| Module3_현황판 | 11_일일대장 오른쪽(O열~) 24시간 현황판 격자·블록·드래그 이동 |
| Module4_일일대장 | 입력 화면: 원데이터->화면(Day_Render), 화면->원데이터 확정(Day_Commit), 날짜 이동, 인쇄 |
| Module5_월대장 | 월 접수대장 (읽기 전용 화면) |
| frmCalendar | 달력 날짜 선택 팝업 |
| Sheet11 / Sheet12 / Sheet13 / 현재_통합_문서 | 10_원데이터 / 11_일일대장 / 12_월대장 / 통합 문서 이벤트 |
