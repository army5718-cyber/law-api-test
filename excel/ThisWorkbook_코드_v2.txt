Option Explicit

' 파일을 열면 엑셀 화면은 숨기고 체크리스트 폼만 표시합니다.
' 폼을 닫거나 오류가 나면 엑셀 화면이 다시 보입니다.
Private Sub Workbook_Open()
    Application.Visible = False
    On Error GoTo fail
    ContForm.Show
    Application.Visible = True
    Exit Sub
fail:
    Application.Visible = True
    MsgBox "체크리스트를 여는 중 오류가 발생했습니다." & vbCrLf & Err.Description, vbExclamation
End Sub
