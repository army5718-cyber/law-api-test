Option Explicit

' 파일을 열면 엑셀 화면(시트)은 숨기고 체크리스트 폼만 먼저 실행합니다.
' 엑셀이 파일을 다 연 뒤(약 1초 후)에 실행해야 숨김이 풀리지 않습니다.
Private Sub Workbook_Open()
    On Error Resume Next
    ThisWorkbook.Windows(1).Visible = False
    Application.Visible = False
    Application.OnTime Now + TimeSerial(0, 0, 1), "'" & ThisWorkbook.Name & "'!StartChecklist"
    On Error GoTo 0
End Sub
