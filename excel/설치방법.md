# 업무 체크리스트 (엑셀 VBA 폼 버전)

첨부하신 `...vba...v3.xlsm`처럼, 왼쪽 트리에서 업무를 고르면 오른쪽에 **확인사항**이 나오는 엑셀 프로그램입니다.
(매크로 파일은 이 환경에서 직접 만들 수 없어, 데이터 파일 + 코드 3개로 드립니다. 약 3분이면 완성됩니다.)

## 만드는 순서
1. `업무체크리스트_데이터.xlsx` 를 엑셀로 열고 **다른 이름으로 저장 → Excel 매크로 사용 통합 문서(*.xlsm)**
   - 시트: `Checklist`(122건 데이터), `Events`(점검 이력)
2. `Alt + F11` (VBA 편집기)
3. 메뉴 **삽입 → 사용자 정의 폼** → 폼을 선택하고 `F4`(속성창)에서 **(이름)을 `ChkForm`** 으로 변경
4. 폼에서 `F7`(코드 보기) → 내용을 모두 지우고 `ChkForm_코드.txt` 전체를 붙여넣기
5. 왼쪽 프로젝트 창에서 **ThisWorkbook** 더블클릭 → `ThisWorkbook_코드.txt` 붙여넣기
6. 메뉴 **삽입 → 모듈** → `모듈_코드.txt` 붙여넣기
7. 저장 후 파일을 다시 열면 체크리스트 창이 뜹니다. (매크로 허용 필요)

## 사용 방법
- 업무분야 ▶ 업무명 ▶ 세부업무 클릭 → 오른쪽에 확인사항 표시
- 검색, 점검주기(일/월/분기/반기/연간/기타) 필터, 전체펼침/접기
- **점검 완료 기록**: Events 시트에 일시가 기록되고, 오늘 완료된 항목은 트리에 `[완료]` 표시 (날짜가 바뀌면 자동으로 미완료로 돌아감)
- 항목을 고치거나 추가하려면 `Checklist` 시트를 직접 수정하면 됩니다 (한 행 = 세부업무 1건, 확인사항 칸의 줄바꿈은 `Alt+Enter`)
- 엑셀 화면을 숨기고 폼만 보이는 것이 싫으면 `ThisWorkbook` 코드의 `Application.Visible = False` 줄을 삭제하세요.

※ 노무업무 1.2의 화면 캡처 이미지는 엑셀 폼에는 넣지 못했습니다(HTML 버전 `checklist.html`에는 있음).
